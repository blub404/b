# Задание 1. Кеширование
Кэширование решает проблему высокой нагрузки на базу данных из-за частых и тяжелых запросов. Вместо того чтобы каждый раз выполнять сложный SQL-запрос к PostgreSQL (что занимает время и ресурсы), приложение может один раз сходить в базу, а результат положить в быстрый in-memory кэш (как Memcached или Redis). Последующие запросы будут получать данные из кэша за миллисекунды, практически не нагружая основную БД. Также кэширование решает проблему низкой скорости ответа приложения: кэшировать имеет смысл данные, к которым наиболее часто осуществляется запрос. Кроме того, кэширование помогает снизить задержки при рендеринге страниц и уменьшить время ответа API. Более широко, кэширование на разных уровнях (DNS, HTTP, CDN, кэш процессора) решает проблему общего узкого места в системе, ускоряя доступ к часто используемой информации
